# Login and Registration System

## Project Description

This project is a Login and Registration System developed using C# Windows Forms.

The original project used Microsoft Access with OleDb. 
For this resubmission, the database connection was converted from OleDb to SQL Server.

## Features

- User Registration
- User Login
- User Logout
- Password validation
- SQL Server database connection

## Technologies Used

- C#
- Windows Forms
- SQL Server
- .NET
- Visual Studio

## Database

The project uses SQL Server as the database.

The database connection is configured through the `App.config` file.

## How to Run

1. Open the project in Visual Studio.
2. Create the required database in SQL Server (Must execute setup_database.sql file).
3. Update the SQL Server connection string in the project.
4. Run the project.
